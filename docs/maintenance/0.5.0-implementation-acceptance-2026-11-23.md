## 范围与实现

本次修改 router-plus 的 Core、React/Vue 适配、公开类型、测试、包版本与使用文档，并同步相邻 pages 的 Router Plus 中英文指南及 API 生成来源。包名和公开子入口保持原有身份，版本为 0.5.0。不修改 Cafe 或 WFJ Campaign Console，不引入消费者业务实现。

| 计划项 | 库侧交付 | 验证或限制 |
| --- | --- | --- |
| P01 单一原生绑定 | ID 绑定继承页面 states 的合同，声明默认值保持权威；创建状态与绑定已有来源共用机制 | 目录继承、原生来源、缺参、历史和异步恢复回归通过；应用重复封装尚未删除 |
| P02 异步就绪 | ready 同步谓词推迟 URL 解码、业务校验及回写；Vue 依赖观察、React 提交后刷新；使用最新地址与有效的待提交用户选择 | 覆盖异步目录、连续导航、无关参数更新、最新 React codec、卸载；业务加载及加载 UI 由 App 持有 |
| P03 历史与失败 | 绑定 history 默认 replace，可选 push；同轮原生修改合并一次导航；守卫拒绝后恢复已提交地址 | push/后退、批量写入、拒绝回滚及真实回执通过；不绕过原生守卫 |
| P04 query 合同 | 沿用 codec；omitDefault 默认关闭，可按组字段覆盖；函数式 query 更新基于最新已提交地址顺序合并，返回 Promise 回执；支持重复参数输入 | 默认省略、false/0/数组、缺参重置、旧闭包和同轮编辑通过；未创建第二份持续状态仓库 |
| P05 保留与释放 | React 可插入仅负责展示的 retained host；库持有缓存、冻结上下文与代际；React/Vue release 均重建子树 | DOM 环境验证保留、释放重建及 React Activity 接入；未进行真实浏览器视觉验收 |
| P06 目标解析审计 | 复用已有 resolveLink/navigate、page+params、origin 与安全规则；未新增业务协议 DSL | 目标矩阵通过；原生未知路径可进入 404，严格已知页面白名单与业务权限仍归 App |
| D01 声明与输入 | 提供 React/Vue 异步绑定与已有 ref 示例，统一 query 输入与实际回执 | 示例 API 与最终包类型检查通过；消费者迁移前后删减清单仍需接入时验证 |
| D02 装配与存活期 | React 工厂增加可选 disposeOnUnmount，只销毁自行创建的 Core；StrictMode 探测清理不销毁存活实例 | StrictMode、真实卸载及外部 Core 归属回归通过；应用 HMR 及旧 history 迁移策略保留 |
| D03 业务消费与守卫 | 保留现有业务状态消费与原生 guard 路径，明确就绪及导航回执边界 | 库守卫拒绝恢复通过；两个应用的未保存表单、鉴权、刷新与首次业务请求时序未验证 |

ready 为同步业务就绪谓词，不是异步请求，也不将 whenReady 改成业务目录加载器。React 使用最近一次提交的校验和 codec 回调，绑定身份、query 归属及字段结构仍为稳定登记合同。Vue 的原生绑定观察依赖；普通自定义桥不具备对任意外部变量的自动观察能力。

## 能力完整性与最终收敛

三子任务及主协调按 Core、框架、使用路径与包体交叉审查。具体需求到实现及用例映射见[能力补全](0.5.0-capability-completion-2026-11-23.md)。局部 query、独立目录订阅、动态规则、锚点、展示宿主、链接行为及完整接线均已实现；原生状态与 query 共用短期地址协调，覆盖先后两种顺序、同轮／慢守卫、真实外部导航取消，保留原生重定向事实。各子任务已完成反向复核，已复现问题关闭。

最终同一 tarball SHA-1 为 e2c7e24912c313486f7e6c1c4f6f5a5671ab5eac。当前依赖严格检查全部 8 个接入配方；最低组合严格检查 7 个配方，唯一排除项是明确需要 React Router >=6.4 的 Data Router 配方。6.0–6.3 的声明式路由支持仍验证通过。早期 Data Router 的 blocker 缺失经官方源码核实并以能力检测适配，DOM 用例覆盖缺失 API；现代原生 blocker 和重定向回归保留通过。没有将条件排除当作该能力在最低版本运行通过。
