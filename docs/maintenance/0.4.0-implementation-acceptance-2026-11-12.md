## 确定的接口边界

- inspectState 仅列出当前门面可见的已安装来源：全局来源与当前页面实例；指定 retained 实例通过 scope(context)。静态地址声明及任意对象字段路径不展开。精确 ID 未安装时返回 null。
- 描述包含 id、scope、pageId、stateKey、parentId、capabilities、queryKeys；列表、描述及嵌套集合冻结，不返回实时值或业务对象。能力只表示适配器操作存在，不替代业务校验／授权。控制台全局门面不增加此方法。
- 配置快照与固定规则缓存不持有实时值缓存；每次操作仍读取原生来源。没有可靠的可变来源失效依据，因此未加入 Store 投影缓存。
- onDiagnostic(error, stage) 保持原签名，不增加公共上下文参数。诊断回调失败不替换主异常或阻断清理。
- 不新增全局 Store、Tab 专用模型、Vue Options API bind/unbind 或 Vue Store 专用适配。计划第 7 节的 handle、selector、防抖、AbortSignal、导览及调试面板继续暂缓。

## 兼容范围调整与实际矩阵

## S6：来源事件与顺序编组的追加交付

用户提出导航、Tab、Panel、Form、按钮调用之间的依赖时序后，确认继续迭代。此项集中进入尚未发布的 0.4.0，未创建 0.4.1。

### 接口与执行边界

- execute(command) 保留原单命令合同；execute(commands, { timeoutMs?, signal? }) 接受相同命令的数组。实例、scope 门面及控制台门面共用处理器。新增 CommandSequenceOptions／CommandSequenceResult。
- 统一订阅新增 state.registered、state.unregistered、state.committed，包含冻结的 StateInspection；disposed 通知关闭。整组登记成功后才发布注册事件，失败回滚不留下注册通知。注销、实例释放、dispose 保持幂等。
- 状态步骤通过事件等待精确来源，支持全局 Store 字段路径匹配已登记父来源；不把静态页面声明当成已经挂载的可操作来源。来源存在后等待恢复及适配器 whenSettled(signal?)。React 在提交后发布访问器与闭包，Vue 使用 nextTick；不使用轮询或固定等待。
- 导航后跟随实际目标 scope；自身导航导致原实例释放不会误取消。等待／执行期间的外部离页、目标释放、销毁和来源身份替换会停止编组。导航 afterEnter 等待期间离页，不会让剩余步骤落到另一个页面。
- 默认整组期限为 10000ms，可设 0—2147483647ms；零立即超时。失败返回 reason、零基 failedIndex 及已有 results。实际已完成回执保留，包含写入成功但提交屏障失败的情况；超时或取消不宣称撤回已发出的调用／导航，不自动重试提交。
- 这不是全应用空闲检测：网络加载、自定义 transition 及业务初始化需由应用回调等待或在可用时才登记依赖来源。普通 hooks 不增加必填参数；单条命令不隐式增加等待。

### 测试发现与修复

React 的真实离线导航链复现了子组件布局阶段先于 Provider 发布新地址的问题：随后 passive 登记可能引用已经释放的旧 scope。现在登记 effect 对比提交上下文，跳过过期候选，等待 external-store 通知后的新上下文再登记，不在旧页面安装来源。

同时统一了 scoped setTab 与普通 tab 状态写入路径；条件渲染 Tab 可用既有 tab.set 命令参加编组，无需恢复专用 Tab 状态模型。
