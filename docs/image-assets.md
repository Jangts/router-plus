# 图片素材规范

本规范适用于本项目实际使用的图片、图标、标志、插画、文档配图及必要原件。具体文件名、尺寸、格式、颜色、用途和消费关系由所属素材清单或应用说明维护，不将某个网站的头像、角色或视觉数值作为其他项目的默认规则。

## 所有权与目录

正式共用原件放 shared/visual-assets，应用及文档中的打包副本按本项目清单消费。生成副本从其来源更新，不单独编辑。相邻项目消费同一品牌时，按各自版本保留明确来源的发布副本，不能依赖另一项目的私有临时目录。

运行素材只保留实际采用的格式与必要原件；不同格式须有独立的实际消费用途，不只为“可编辑”保留同用途双版。素材以稳定用途命名，避免生成版本、画风或编辑过程后缀。替换时同步 import、清单、预加载、引用、说明和实际消费副本。

设计提示词、候选稿、实验与制作记录归 development。问题参考图和经授权拍摄的验证截图放 .tmp/screenshots，用后删除，不加入程序素材、文档发布资源或镜像。用户指定保留的原件、正式备份及独立外部工程按各自边界维护。

## 无损压缩

压缩保持尺寸、颜色模式、位深、完整 RGBA 像素（含透明区域 RGB）、透明通道及颜色元数据。无损优化不缩放、不量化、不重绘、不清除透明区 RGB，也不以肉眼近似相同代替校验。只采用更小且验证等价的结果。

PNG 优化可以使用保持位深、颜色类型与元数据的编码选项。工具是否可用及实际命令由本项目登记；没有相应工具时不虚构自动压缩流程。不得将一个项目的安装、同步或内建发布工具作为其他项目的默认入口。

按展示用途另行生成有尺寸上限的衍生文件时，明确缩放、方向、格式和颜色策略；保留原稿，并将衍生用途与原稿无损压缩分别验证。压缩不改变既有素材的外观认可状态，不改页面 CSS 尺寸、布局或交互。

## 素材与交付一致性

素材清单记录身份、用途、来源和实际消费者；构建或同步入口读取同一声明。对生成副本核对名称、文件集合、字节或内容摘要，拒绝旁路修改。随库、应用或文档站分别打包其真正需要的素材。

素材处理不自动授权修改业务数据、运行内容、内建 release 或部署。需要维护这类内容时，继续使用所属项目的已登记流程。运行验证与视觉验收分别记录；未明确授权时不打开 UI、不截图。

本项目的素材来源与同步入口见[Workspace 结构](workspace.md)和[项目检查入口](review-entrypoints.md)。
