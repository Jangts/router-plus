# Router Plus

Router Plus provides routing and native state bindings for React and Vue, including retained views, highlighting and guided tours.

[SDK quickstart / SDK 快速开始](packages/router-plus/README.md) · [Documentation / 在线文档](https://router-plus-docs.pages.jangts.cafe/) · [Project docs / 项目文档](docs/README.md)

The SDK lives in `packages/router-plus/`. The documentation site in `apps/router-plus-docs/` generates its API pages from the SDK source in the same checkout.

From the repository root, use Node.js 22.12 or later and run:

```sh
npm ci
npm run build
npm run build:docs:router-plus
```

See the [workspace guide](docs/workspace.md) and [documentation deployment guide](apps/router-plus-docs/docs/deployment.md) for repository commands and publish targets.
